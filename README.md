## 🎮 משחקים

| משחק | תיקייה | תיאור |
|---|---|---|
| 🚀 מרוץ החשבון | [`multiplication-game`](multiplication-game/) | כפל, חילוק, חיבור וחיסור בקול (בוחרים פעולות וטווח מספרים 0–20), נגד השעון או בלי זמן, עם טבלת שיאים |
| 🐍 סולמות ונחשים | [`snakes-ladders`](snakes-ladders/) | 2–5 שחקנים, לוח 100 או 200, 1–3 קוביות לבחירה, תרגילי חיבור אופציונליים |

| 🔤 מסע המילים | [`english-vocab`](english-vocab/) | 46 מילים באנגלית מ-4 רשימות של כיתה ד׳, 6 מצבים: להגיד בקול (המשחק שומע בעברית ובודק), לבחור תשובה, איות (גם רמה קשה עם כל האותיות), להקשיב ולבחור, זוגות זיכרון (6–12 זוגות) ומרוץ 60 שניות. ההתקדמות נשמרת במכשיר |
| 🚗 מי המותג? | [`car-logos`](car-logos/) | 387 סמלי יצרני רכב מכל העולם. רואים סמל ואומרים בקול או כותבים את שם המותג, בעברית או באנגלית, גם עם שגיאות כתיב. מותגים מוכרים או כל העולם, עם או בלי סמלים שהשם כתוב בהם, רמזים, ניקוד ושיא |
