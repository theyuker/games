# 💸 ספליט מקדאסי

חלוקת הוצאות טיול בין חברים: כל אחד מכניס מה ששילם ועל מי זה מתחלק, ובסוף כל אחד יודע למי להעביר וכמה.

- **כתובת:** https://split-makdasi.vercel.app
- **איפה זה רץ:** Vercel (פרויקט `split-makdasi`), עם Vercel Blob לשמירת הנתונים. לא רץ על GitHub Pages, כי צריך שרת.
- **הקוד:** בתיקייה `src/` — `index.html` (כל הממשק), `api/trip.js` (השרת), `package.json`, `vercel.json`.
- הקובץ `index.html` שבתיקייה הזו רק מעביר לכתובת ב-Vercel.

## מה יש בה
- קבוצה לכל טיול, הזמנה בקישור בוואטסאפ, בלי הרשמה
- שקל / דולר / יורו עם שער יציג מתעדכן
- חלוקה על "כולם" (כולל מי שמצטרף אחר כך) או על משתתפים נבחרים
- חלוקה לפי ימים או לילות של כל משתתף
- התחשבנות: כולם מעבירים למרכז אחד, או העברות ישירות
- כמה כל אחד משלם בסך הכול
